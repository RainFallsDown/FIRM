# 场景参数记录

这份文档专门记录当前已经确认的场景搭建参数，作为后续 FIRM 仿真 `setup`、asset 尺寸和摆位的参考。

## 1. 桌子

- 桌子前后深度：`54 cm`
- 桌子左右总宽度：`100 cm`
- 桌子高度：`71 cm`
- 说明：这里的“宽度”指的是桌子的前后深度；桌子左右总宽度现已补充为 `100 cm`。

## 2. 本体

- 本体左后方到桌子：`43 cm`
- 本体右后方到桌子：`43 cm`
- 本体左下到桌子左腿：`33 cm`
- 本体右下到桌子右腿：`43 cm`

## 3. 架子

- 架子左侧到桌子左边缘：`16.5 cm`
- 架子右侧到桌子右边缘：`29.2 cm`
- 架子左侧距离桌子：`4.8 cm`
- 架子右侧距离桌子：`1.1 cm`

## 4. 纸盒与物料

- 胶带直径：`9.5 cm`
- 胶带芯内径：`7.62 cm`（当前采用与 3 英寸纸芯一致的资料先验）
- 胶带厚度 / 宽度：`1 cm`
- 盒子尺寸：`24.5 x 18 x 5 cm`
- 盒子壁厚：`3 mm`
- 说明书展开尺寸：`15 x 20 cm`
- 海绵垫尺寸：
  - 长度：纸盒长度的 `80%`
  - 宽度：纸盒宽度的 `80%`
  - 厚度：`1 mm`
- 海绵垫说明：按薄片处理

## 5. 已确认的材料与形态

- 海绵垫：`薄泡棉`，不是织物垫，也不按厚块开孔海绵处理。
- 说明书：`5 张完整纸`，每张暂按 `0.1 mm`，总厚度 `0.5 mm`；正式场景将五层纸张组成一个装订说明书刚体代理，不设置中央合页，暂不求解单页弯曲和页间滑移。
- 鼠标线缆：按照片中的成束黑色鼠标/USB 柔性线缆处理，并与刚性鼠标端物理连接。
- 鼠标线缆公开资料先验：外径约 `4.6–5.5 mm`、PVC 护套、线密度约 `34–39 g/m`。

## 6. 架子与关节补充说明

- 架子倾斜角：`30°`
- 说明：当前按 `30°` 记录，作为场景初始搭建参数。

- 本体关节 `joint31-34`：
  - `可以动态调整`
  - 说明：头部相关角度允许调节。

- 视角说明：
  - 采集数据时使用的是 `固定视角`
  - 关节本身仍然 `可以动态调整`

## 7. 当前未定项

以下内容目前仍未完全确认，后续如有更多资料继续补充：

- 本体和架子在统一世界坐标系下的完整姿态定义
- 薄泡棉的具体聚合物（PU、PE 或 EVA）和质量
- 五张说明书的实际纸张克重；当前暂用普通 `80 g/m²` 纸张先验，总质量约 `12 g`
- 鼠标线缆的准确型号、总长度和整套质量
- 机器人夹爪接触垫的材料与硬度
